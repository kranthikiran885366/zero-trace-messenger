### **End-to-End Encryption**

- **RSA-4096 Key Exchange**: Secure key establishment
- **Perfect Forward Secrecy**: New keys for each session
- **Zero-Knowledge Architecture**: No data stored on servers

## 🚀 Getting Started

### **Prerequisites**
- Node.js 18+ (recommended: use [nvm](https://github.com/nvm-sh/nvm))
- Modern browser with WebRTC support
- HTTPS connection (required for WebRTC)

### **Installation**

```bash
# Clone the repository
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start development server
npm run dev
```

### **Environment Setup**
Create a `.env` file for configuration:
```env
VITE_WEBSOCKET_URL=ws://localhost:8080
VITE_STUN_SERVERS=stun:stun.l.google.com:19302
VITE_DEBUG_MODE=false
```

2. Click Share → Publish

#### **Self-Hosting**
1. Build the application: `npm run build`
2. Deploy `dist/` folder to web server
3. Configure HTTPS (required for WebRTC)
4. Set up WebSocket server for real-time features

#### **Docker Deployment**
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY dist/ ./dist/
EXPOSE 3000
CMD ["npx", "serve", "-s", "dist", "-l", "3000"]
```
